# QueueLess

## Intelligent Real-Time Crowd Monitoring and Queue Optimization System

QueueLess is a multidisciplinary engineering project designed to monitor queues, estimate waiting time, analyse crowd trends, predict future crowd conditions, and provide intelligent queue management recommendations.

## Objectives

- Monitor the number of people in a queue
- Estimate waiting time
- Calculate arrival and service rates
- Analyse crowd growth
- Determine congestion level
- Predict future crowd conditions
- Suggest suitable visiting periods
- Recommend additional counters when required
